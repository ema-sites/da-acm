# breadcrumb

Custom **custom** block. Purpose: breadcrumb trail (Home > ancestors > current page) generated from the URL path.

## Authoring (Document Authoring)

Model: `auto-blocked`

Usually authored as default content; the block is constructed automatically. Content: not authored; scripts/scripts.js inserts it at the top of main on every page except the homepage. Ancestor path segments are title-cased and linked; the current page shows its h1 or title. Opt out with page metadata breadcrumb: off. Optional authored form: one row with links, used as the trail.

## Supported variations

No variations.
