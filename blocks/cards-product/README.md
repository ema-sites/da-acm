# cards-product

Custom **cards** block. Purpose: product / extension tiles in a 4-column grid: logo, name, vendor, star rating, partner badge, price.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row per product; cells (any may be omitted, recognised by content): logo image, product name (heading or link to the product), vendor, rating (number 0-5, e.g. 4.5), partner badge (text containing "Partner", e.g. Gold Technology Partner), price (e.g. $99.00 or $75.00 / year).

No variations.
