# carousel-promo

Custom **carousel** block. Purpose: promotional banner slider; each slide has a logo, heading, text and CTA button beside a large image.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row per slide; cells: content (logo image, heading, text, CTA link) and image, in either order.
